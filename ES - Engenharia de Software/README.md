# ES - Engenharia de Software

**Course:** Software Engineering I  
**Semester:** 2024/2  
**University:** Universidade Federal de Minas Gerais (UFMG), Department of Computer Science (DCC)

Practical labs based on the book Engenharia de Software Moderna (Prof. Marco Tulio Valente) plus a group project. The starter code of the labs comes from the course material, the exercises are mine.

## Contents

| Folder | Description | Tech |
|---|---|---|
| [Roteiro_Pratico_1_Microsservicos](Roteiro_Pratico_1_Microsservicos) | Microservices lab (micro-livraria): Node.js, gRPC, REST and Docker. | JavaScript, gRPC, Docker |
| [Roteiro_Pratico_2_Refactoring](Roteiro_Pratico_2_Refactoring) | Refactoring lab based on the first chapter of Martin Fowler's book. | JavaScript |
| [TP 1](TP%201) | es-call: ticket management system (backend, frontend and database in containers). | TypeScript, Express, PostgreSQL, Docker |
| [TP 2](TP%202) | Testing exercises: unit tests (shopping cart and library system), integration tests, end-to-end tests with Cypress and continuous integration. | Java, JUnit, JavaScript, Jest, Cypress, Maven |

Most code comments and reports are written in Portuguese.
