# Roteiro_Pratico_2_Refactoring

**Lab 2: Refactoring**  
Course: [ES - Engenharia de Software](../README.md) (Software Engineering I), 2024/2

Refactoring lab based on the first chapter of Martin Fowler's book "Refactoring": an invoice generator for a theater company, refactored step by step into classes and modules.

## Files

- [`RoteiroRefactoringJS/`](RoteiroRefactoringJS): Refactored code and the lab instructions in its README.

## How to run

```bash
cd RoteiroRefactoringJS
node index.js
```

Comments in the code and reports are in Portuguese unless noted otherwise.
