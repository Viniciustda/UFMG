# Roteiro_Pratico_1_Microsservicos

**Lab 1: Microservices**  
Course: [ES - Engenharia de Software](../README.md) (Software Engineering I), 2024/2

Lab with micro-livraria, a small online bookstore split into microservices (frontend, controller, inventory and shipping) that talk through REST and gRPC and run in Docker. The full instructions are in `micro-livraria/README.md`.

## Files

- [`micro-livraria/`](micro-livraria): Project code. Starter code from the course material (Prof. Marco Tulio Valente).

## How to run

```bash
cd micro-livraria
npm install
npm start
```

Comments in the code and reports are in Portuguese unless noted otherwise.
