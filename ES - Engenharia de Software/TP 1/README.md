# TP 1

**TP 1: es-call**  
Course: [ES - Engenharia de Software](../README.md) (Software Engineering I), 2024/2

Group project: es-call, a system to manage support tickets. Customers open tickets, the manager assigns them to technicians with a priority, and technicians close them. The backend is in TypeScript with Express and PostgreSQL, and everything runs with Docker Compose. Details are in `es-call/README.md`.

## Files

- [`es-call/`](es-call): Backend, frontend, database scripts and diagrams.

## How to run

```bash
cd es-call
docker compose up
```

Comments in the code and reports are in Portuguese unless noted otherwise.
