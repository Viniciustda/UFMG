# TP 02

**TP 2: Pipelined RISC-V processor**  
Course: [OC I - Organização de Computadores I](../README.md) (Computer Organization I), 2023/2

Group project: pipelined RISC-V processor without forwarding, with a hazard detection unit, described in Verilog and simulated in Google Colab.

## Files

- [`OC1_RISCV_TP2.ipynb`](OC1_RISCV_TP2.ipynb): Jupyter notebook with the solution.
- [`Relatório TP2 - OC1.pdf`](Relat%C3%B3rio%20TP2%20-%20OC1.pdf): Report (Portuguese).
- [`enunciado.pdf`](enunciado.pdf): Assignment statement (Portuguese).

## How to run

Open the notebook in Google Colab. It installs the Verilog tools and runs the simulation.

Comments in the code and reports are in Portuguese unless noted otherwise.
