# TP 1 - Processamento Distribuído de Dados

**TP 1: Distributed data processing**  
Course: [CN - Computação em Nuvem](../README.md) (Cloud Computing), 2025/2

Big data analysis of a Spotify playlists dataset with Apache Spark reading from HDFS, for example song duration statistics and outlier removal with the interquartile range.

## Files

- [`TP1 - Processamento Distribuído de Dados.ipynb`](TP1%20-%20Processamento%20Distribu%C3%ADdo%20de%20Dados.ipynb): Jupyter notebook with the solution.
- [`TP1 - Processamento Distribuído de Dados.pdf`](TP1%20-%20Processamento%20Distribu%C3%ADdo%20de%20Dados.pdf): Report (Portuguese).

## How to run

Open the notebook in a Jupyter environment with PySpark and access to the dataset on HDFS.

Comments in the code and reports are in Portuguese unless noted otherwise.
