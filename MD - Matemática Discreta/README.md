# MD - Matemática Discreta

**Course:** Discrete Mathematics  
**Semester:** 2020/2 and 2021/1  
**University:** Universidade Federal de Minas Gerais (UFMG), Department of Computer Science (DCC)

Practical assignment: given an integer n >= 0, print the (x, y) coordinates of point n on the square spiral and on the triangular spiral.

## Contents

| Folder | Description | Tech |
|---|---|---|
| [espquadrada.c, esptriangular.c](espquadrada.c) | Submitted solutions for the square and triangular spirals (see leiame.txt and espirais.pdf). | C |
| [Versões](Vers%C3%B5es) | Alternative versions of the same algorithms with O(1), O(n) and sub-linear complexity. | C |

Most code comments and reports are written in Portuguese.
