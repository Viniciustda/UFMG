# RI - Recuperação de Informação

**Course:** Information Retrieval  
**Semester:** 2026/1  
**University:** Universidade Federal de Minas Gerais (UFMG), Department of Computer Science (DCC)

Building the main pieces of a search engine, from crawling to ranking.

## Contents

| Folder | Description | Tech |
|---|---|---|
| [TP 1 - Web Crawler](TP%201%20-%20Web%20Crawler) | Multithreaded web crawler (frontier, fetcher, parser and storage), with documentation. | Python |
| [TP 2 - Indexador e Processador de Consultas](TP%202%20-%20Indexador%20e%20Processador%20de%20Consultas) | Inverted index builder with limited memory and a query processor (document-at-a-time, TF-IDF and BM25), with documentation. | Python |
| [RC - Entity Search](RC%20-%20Entity%20Search) | Research challenge (Kaggle in-class) on entity ranking over 4.6M entities: BM25, BM25F, RM3, dense retrieval, cross-encoder re-ranking, learning to rank and rank fusion. | Python |

## Notes

- Datasets, caches and the generated indexes were left out because of their size (several GB).

Most code comments and reports are written in Portuguese.
