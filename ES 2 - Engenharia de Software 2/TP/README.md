# TP

**TP: Medical appointment system**  
Course: [ES 2 - Engenharia de Software 2](../README.md) (Software Engineering II), 2025/1

Group project (in pairs): a Flask web app to register doctors and patients and schedule appointments, with unit, integration and system (Selenium) tests and a CI workflow. Details are in `Sistema Agendamento Medico/README.md`.

## Files

- [`Sistema Agendamento Medico/`](Sistema%20Agendamento%20Medico): Application, tests and CI workflow.

## How to run

```bash
cd "Sistema Agendamento Medico"
pip install -r requirements.txt
python run.py
pytest
```
