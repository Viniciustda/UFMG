# PDS 1 - Programação e Desenvolvimento de Software 1

**Course:** Programming and Software Development I  
**Semester:** 2020/1  
**University:** Universidade Federal de Minas Gerais (UFMG), Department of Computer Science (DCC)

First programming course, taught in C: from the first "hello world" to files, matrices, modules and a small game built with the Allegro library.

## Contents

| Folder | Description | Tech |
|---|---|---|
| `Aula *` | Small programs written during lectures (input/output, loops, matrices, files, strings, modules). | C |
| `Pratica *` | Weekly lab exercises (Pratica 10 introduces graphics and games with Allegro 5). | C, Allegro 5 |
| [Prova 1 - A, Prova 2 - A, Prova 3](Prova%201%20-%20A) | Programming exams. | C |
| [TP](TP) | Final project: a Space Invaders game (move with A/D, shoot with SPACE). | C, Allegro 5 |

Most code comments and reports are written in Portuguese.
