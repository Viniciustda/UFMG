## How to run

```bash
make   # Windows with MinGW and Allegro 5.0.10 installed in C:\
```

## Notes

- The Makefile expects Allegro 5.0.10 for MinGW 4.7.0 in `C:\`. The `.dll` file is the Allegro runtime for Windows.

Comments in the code and reports are in Portuguese unless noted otherwise.
