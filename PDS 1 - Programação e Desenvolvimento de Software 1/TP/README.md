# TP

**TP: Space Invaders**  
Course: [PDS 1 - Programação e Desenvolvimento de Software 1](../README.md) (Programming and Software Development I), 2020/1

Final project: a Space Invaders game in C with the Allegro 5 library. Move the cannon with A and D and shoot with SPACE. The game keeps a high score file.

## Files

- [`TP - Vinicius Trindade/`](TP%20-%20Vinicius%20Trindade): My game: `Tp.c`, Makefile, font, Allegro DLL and the report (`Documentacao - Vinicius Trindade.pdf`).
- [`TP - Vinicius Trindade.zip`](TP%20-%20Vinicius%20Trindade.zip): Zip file that was submitted.
- [`enunciado/`](enunciado): Statement, the instructor's example game and assets.
- [`exemplosDoc/`](exemplosDoc): Example reports given by the instructor.

## How to run

```bash
cd "TP - Vinicius Trindade"
make   # Windows with MinGW and Allegro 5.0.10 installed in C:\
Tp.exe
```

Comments in the code and reports are in Portuguese unless noted otherwise.
