# Compiladores I

**Course:** Compilers I  
**Semester:** 2024/2  
**University:** Universidade Federal de Minas Gerais (UFMG), Department of Computer Science (DCC)

A compiler for a small functional language built step by step. Each numbered folder is one lab that extends the previous one.

## Contents

| Folder | Description | Tech |
|---|---|---|
| `1 - 4` | Lexer, representation and parsing of arithmetic expressions, variables. | Python |
| `5 - 6` | Visitor pattern and dynamic type checking. | Python |
| `7 - 10` | Type inference, anonymous functions, recursive functions and static type checking. | Python |
| `11 - 14` | Code generation for arithmetic, variable renaming, control flow and functions (RISC-V assembly). | Python |
| `15` | Register allocation for linear code. | Python |

Most code comments and reports are written in Portuguese.
