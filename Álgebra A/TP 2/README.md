# TP 2

**TP 2: Quadratic sieve**  
Course: [Álgebra A](../README.md) (Algebra A (number theory)), 2024/1

Group project: the quadratic sieve algorithm to factor very large integers, using Tonelli-Shanks/Cipolla to compute modular square roots.

## Files

- [`TP2 - Álgebra A.pdf`](TP2%20-%20%C3%81lgebra%20A.pdf): Report (Portuguese).
- [`Tp_AlgA.ipynb`](Tp_AlgA.ipynb): Jupyter notebook with the solution.
- [`Trabalho2AlgebraA_2024.pdf`](Trabalho2AlgebraA_2024.pdf): Assignment statement (Portuguese).

## How to run

Open the notebook in Jupyter or Google Colab. It installs sympy, gmpy2 and numpy.

Comments in the code and reports are in Portuguese unless noted otherwise.
