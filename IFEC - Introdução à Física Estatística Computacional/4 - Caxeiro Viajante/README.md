# 4 - Caxeiro Viajante

**Task 4: Traveling salesman**  
Course: [IFEC - Introdução à Física Estatística Computacional](../README.md) (Introduction to Computational Statistical Physics), 2024/2

Traveling salesman problem solved with simulated annealing for 10 to 150 cities.

## Files

- [`7 - Caixeiro Viajante.pdf`](7%20-%20Caixeiro%20Viajante.pdf): Assignment statement (Portuguese).
- [`Caxeiro_Viajante.ipynb`](Caxeiro_Viajante.ipynb): Jupyter notebook with the solution.
- [`Caxeiro_Viajante.pdf`](Caxeiro_Viajante.pdf): PDF export of the notebook.
- [`caxeiro_viajante.py`](caxeiro_viajante.py): Script version (reads the cities from a file).
- [`exemplo_de_entrada.txt`](exemplo_de_entrada.txt): Example input.

## How to run

Open the notebook in Jupyter or Google Colab. Script version:

```bash
python3 caxeiro_viajante.py exemplo_de_entrada.txt
```

Comments in the code and reports are in Portuguese unless noted otherwise.
