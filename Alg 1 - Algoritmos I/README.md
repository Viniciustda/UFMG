# Alg 1 - Algoritmos I

**Course:** Algorithms I  
**Semester:** 2023/1 and 2023/2  
**University:** Universidade Federal de Minas Gerais (UFMG), Department of Computer Science (DCC)

Graph algorithms, greedy and exact algorithms and dynamic programming. I took the course twice: the lowercase folders (`tp1`, `tp2`, `tp3`) are the 2023/1 assignments, with Makefile, test cases and report, and the `TP 0x` folders are the 2023/2 assignments, with statement and solution.

## Contents

| Folder | Description | Tech |
|---|---|---|
| [tp1](tp1) | 2023/1: shortest path between two cities using only even-length roads and an even number of roads. | C++ |
| [tp2](tp2) | 2023/1: job matching on a bipartite graph, with a greedy algorithm and an exact (maximum matching) algorithm. | C++ |
| [tp3](tp3) | 2023/1: minimum number of metal alloys to meet a demand, solved with dynamic programming. | C++ |
| [TP 01](TP%2001) | 2023/2: planar graphs (map regions and their borders). | C++ |
| [TP 02](TP%2002) | 2023/2: optimization problems on temporal graphs. | C++ |
| [TP 03](TP%2003) | 2023/2: "De boa na Radlândia", from the algorithm design paradigms module. | C++ |

Most code comments and reports are written in Portuguese.
