# TP 01

**TP 1: Planar graphs**  
Course: [Alg 1 - Algoritmos I](../README.md) (Algorithms I), 2023/2

Problem about planar graphs inspired by map coloring (regions and their borders).

## Files

- [`Grafos Planares.cpp`](Grafos%20Planares.cpp): Solution (reads from standard input).
- [`TP1-Algoritmos-I.pdf`](TP1-Algoritmos-I.pdf): Assignment statement (Portuguese).

## How to run

```bash
g++ -O2 -o planares "Grafos Planares.cpp"
./planares < input.txt
```

Comments in the code and reports are in Portuguese unless noted otherwise.
