# TP 2

**TP 2: Open data database**  
Course: [IBD - Introdução a Banco de Dados](../README.md) (Introduction to Databases), 2021/2

Group project: database built from the 2021 class offerings open data of the Federal University of Sergipe (UFS). Includes the ER and relational diagrams and SQL queries in a notebook.

## Files

- [`Apresentação1.pdf`](Apresenta%C3%A7%C3%A3o1.pdf): Presentation slides.
- [`ENTIDADES-Page-1-er.png`](ENTIDADES-Page-1-er.png): ER diagram.
- [`ENTIDADES-Page-2-relacional.png`](ENTIDADES-Page-2-relacional.png): Relational diagram.
- [`ENTIDADES.drawio`](ENTIDADES.drawio): Diagrams (draw.io).
- [`TP/`](TP): Notebook with data loading and SQL queries.
- [`tur-csv-turmas-de-2021.csv`](tur-csv-turmas-de-2021.csv): Source dataset.

## How to run

Open `TP/TP_IBD_2.ipynb` in Jupyter or Google Colab. It loads `tur-csv-turmas-de-2021.csv`.

Comments in the code and reports are in Portuguese unless noted otherwise.
