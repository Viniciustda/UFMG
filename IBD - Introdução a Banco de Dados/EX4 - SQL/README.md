# EX4 - SQL

**Exercise 4: SQL**  
Course: [IBD - Introdução a Banco de Dados](../README.md) (Introduction to Databases), 2021/2

SQL queries over the database of a fictional consulting company (consultants, projects, clients and trips), run with SQLite in Google Colab.

## Files

- [`EX4_SQL_ViniciusTrindade.ipynb`](EX4_SQL_ViniciusTrindade.ipynb): Jupyter notebook with the solution.
- [`ex4_sql_ViniciusTrindade.py`](ex4_sql_ViniciusTrindade.py): Script version of the notebook.

## How to run

Open the notebook in Google Colab. It downloads the database and runs the queries.

Comments in the code and reports are in Portuguese unless noted otherwise.
