# DJD - Desenvolvimento de Jogos Digitais

**Course:** Digital Game Development  
**Semester:** 2025/2  
**University:** Universidade Federal de Minas Gerais (UFMG), Department of Computer Science (DCC)

2D and 3D games in C++ with SDL2 and OpenGL, built on the course's game engine template. Each TP README lists the features I implemented and the local build adjustments.

## Contents

| Folder | Description | Tech |
|---|---|---|
| [TP 0 - Configuração Inicial](TP%200%20-%20Configura%C3%A7%C3%A3o%20Inicial) | Environment setup and a simple interactive SDL2 application. | C++, SDL2, CMake |
| [TP 1 - Pong](TP%201%20-%20Pong) | Pong. | C++, SDL2, OpenGL |
| [TP 2 - Asteroids](TP%202%20-%20Asteroids) | Asteroids. | C++, SDL2, OpenGL |
| [TP 3 - Super Mario Bros](TP%203%20-%20Super%20Mario%20Bros) | Super Mario Bros world 1-1 with tile maps, enemies, audio and new features. | C++, SDL2, OpenGL |
| [TP 4 - Star Fox](TP%204%20-%20Star%20Fox) | 3D rail shooter inspired by Star Fox. | C++, SDL2, OpenGL |
| [TP Final - Contra-Diction](TP%20Final%20-%20Contra-Diction) | Team final game: a 2D action platformer. Only the source code, shaders and screenshots are here. The art assets (about 140 MB) were left out because of their size. | C++, SDL2, OpenGL |

## Notes

- Build folders (`cmake-build-*`) and IDE settings were left out. Open each TP folder with CMake (or CLion) to build it.

Most code comments and reports are written in Portuguese.
