# DJD - Desenvolvimento de Jogos Digitais

**Course:** Digital Game Development  
**Semester:** 2025/2  
**University:** Universidade Federal de Minas Gerais (UFMG), Department of Computer Science (DCC)

2D and 3D games in C++ with SDL2 and OpenGL, built on the course's game engine template. Each TP README lists the features I implemented and the local build adjustments.

## Contents

| Folder | Description | Tech |
|---|---|---|
| TP 0 - Configuração Inicial | Environment setup and a simple interactive SDL2 application. *Private for now, not published in this repository.* | C++, SDL2, CMake |
| TP 1 - Pong | Pong. *Private for now, not published in this repository.* | C++, SDL2, OpenGL |
| TP 2 - Asteroids | Asteroids. *Private for now, not published in this repository.* | C++, SDL2, OpenGL |
| TP 3 - Super Mario Bros | Super Mario Bros world 1-1 with tile maps, enemies, audio and new features. *Private for now, not published in this repository.* | C++, SDL2, OpenGL |
| TP 4 - Star Fox | 3D rail shooter inspired by Star Fox. *Private for now, not published in this repository.* | C++, SDL2, OpenGL |
| [TP Final - Contra-Diction](TP%20Final%20-%20Contra-Diction) | Team final game. Only the source code, shaders and screenshots are here. The art assets (about 140 MB) are in the original repository. | C++, SDL2, OpenGL |

## Notes

- Build folders (`cmake-build-*`) and IDE settings were left out. Open each TP folder with CMake (or CLion) to build it.
