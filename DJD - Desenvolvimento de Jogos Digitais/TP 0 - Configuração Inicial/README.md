## Funcionalidades e Interações

Este projeto implementa uma aplicação gráfica simples utilizando a biblioteca SDL2 com as seguintes interações:

* **Arrastar Figuras:** Pressione o **botão direito** do mouse sobre qualquer uma das figuras (quadrados ou círculo) e arraste para movê-la pela tela.

* **Redimensionar Figuras:** Pressione o **botão esquerdo** do mouse sobre uma figura e, sem soltar, arraste o mouse na **horizontal**. Arrastar para a direita aumenta o tamanho, e para a esquerda, diminui.

* **Mudar a Cor:** Dê um **clique duplo com o botão esquerdo** do mouse sobre qualquer figura para que ela mude para uma cor aleatória.

* **Fechar o Programa:** Clique no botão 'X' da janela para encerrar a aplicação.
