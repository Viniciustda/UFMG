# TP

**TP: Premier League data analysis**  
Course: [ICD - Introdução à Ciência de Dados](../README.md) (Introduction to Data Science), 2024/1

Group project analyzing English Premier League data (standings from 2000 to 2022 and player data) with confidence intervals and bootstrap.

## Files

- [`Projeto.ipynb`](Projeto.ipynb): Jupyter notebook with the solution.
- [`datasets/`](datasets): Input datasets.
- [`outputs/`](outputs): Generated figures.

## How to run

Open `Projeto.ipynb` in Jupyter or Google Colab.

Comments in the code and reports are in Portuguese unless noted otherwise.
