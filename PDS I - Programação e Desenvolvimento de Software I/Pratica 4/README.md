## How to run

```bash
# module version (all exercises as functions):
gcc -o teste pratica4.c testePratica4.c -lm
./teste

# each "PDS1 - Pratica4 - At*.c" file is also a standalone program:
gcc -o fatorial "PDS1 - Pratica4 - At09 - fatorial.c" && ./fatorial
```

Comments in the code and reports are in Portuguese unless noted otherwise.
