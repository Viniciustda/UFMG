# IR - Introdução à Robótica

**Course:** Introduction to Robotics  
**Semester:** 2026/1  
**University:** Universidade Federal de Minas Gerais (UFMG), Department of Computer Science (DCC)

Team projects (team Gambiarra Tech) with Arduino robots, from a drawing arm to a mobile robot with perception.

## Contents

| Folder | Description | Tech |
|---|---|---|
| TP 1 - Braço SCARA | "Robot artist": SCARA arm that draws shapes, with photos of the build. *Private for now, not published in this repository.* | Arduino (C++) |
| TP 2 - Robô Móvel Seguidor de Cores | Mobile robot that identifies colors, plus encoder calibration and sensor test sketches and the 3D printed support model. *Private for now, not published in this repository.* | Arduino (C++) |
| TP 3 - Robô Móvel com Percepção | Perception and closed-loop control of a mobile robot (Arduino Mega 2560). *Private for now, not published in this repository.* | C++, PlatformIO |
| Competição - Busca e Resgate | Search and rescue competition. Same code base as TP 3, kept as a separate project. *Private for now, not published in this repository.* | C++, PlatformIO |
| [Lista 1](Lista%201) | Exercise list on coordinate frames and transformations. | Python, Jupyter |

Most code comments and reports are written in Portuguese.
