# TP 1

**TP 1: URL scheduler**  
Course: [ED - Estruturas de Dados](../README.md) (Data Structures), 2021/2

URL scheduler for a web crawler: keeps hosts in a queue and URLs of each host in a list, with commands to add, schedule and list URLs.

## Files

- [`Documentacao.pdf`](Documentacao.pdf): Report (Portuguese).
- [`TP/`](TP): Source code (`src/`), headers (`include/`) and Makefile.
- [`tp1_escalonador.pdf`](tp1_escalonador.pdf): Assignment statement (Portuguese).

## How to run

```bash
cd TP
mkdir -p obj bin
make
./bin/tp1 input.txt
```

Comments in the code and reports are in Portuguese unless noted otherwise.
