# PA

**Practice problems**  
Course: [ED - Estruturas de Dados](../README.md) (Data Structures), 2021/2

Short practice problems solved during the course (many come from online judges). Each file starts with the problem statement in a comment.

## Files

- [`PA 1 - Corvo de 3 olhos.c`](PA%201%20-%20Corvo%20de%203%20olhos.c): Lottery results (counting).
- [`PA 2 - Diamantes e Areia.c`](PA%202%20-%20Diamantes%20e%20Areia.c): Counting diamonds `<>` with a stack.
- [`PA 3 - Camisetas.cpp`](PA%203%20-%20Camisetas.cpp): Sorting T-shirts.
- [`PA 4 - Descobrindo Senha.c`](PA%204%20-%20Descobrindo%20Senha.c): Password discovery.
- [`PA 5 - Codifique a Arvore.cpp`](PA%205%20-%20Codifique%20a%20Arvore.cpp): Tree encoding.
- [`PA 6 - Array Hash.cpp`](PA%206%20-%20Array%20Hash.cpp): Hash of strings.

## How to run

```bash
gcc -o pa1 "PA 1 - Corvo de 3 olhos.c" && ./pa1 < input.txt
g++ -o pa6 "PA 6 - Array Hash.cpp" && ./pa6 < input.txt
```

Comments in the code and reports are in Portuguese unless noted otherwise.
