# Redes neurais anteriores

**Earlier neural networks**  
Course: [Nanocomputação](../README.md) (Nanocomputing), 2025/2

First neural network scripts written before the final project: data preparation, a simplified ResNet style CNN, training and testing.

## Files

- [`1 - preparar_dados.py`](1%20-%20preparar_dados.py): Prepares the dataset.
- [`1 - rede_neural.py`](1%20-%20rede_neural.py): First CNN (simplified ResNet).
- [`1 - testar_modelo.py`](1%20-%20testar_modelo.py): Tests the trained model.
- [`2-rede.py`](2-rede.py): Second network, with command line options.
- [`2-teste.py`](2-teste.py): Tests the second network.

## Notes
