# TP 03

**TP 3: De boa na Radlândia**  
Course: [Alg I - Algoritmos I](../README.md) (Algorithms I), 2023/2

Problem from the algorithm design paradigms module, set in a skateboarding community.

## Files

- [`TP3-Algoritmos-I.pdf`](TP3-Algoritmos-I.pdf): Assignment statement (Portuguese).
- [`caso teste/`](caso%20teste): Example input and expected output.
- [`radlandia.cpp`](radlandia.cpp): Solution (reads from standard input).
- [`rascunho.cpp`](rascunho.cpp): Draft used while developing the solution.

## How to run

```bash
g++ -O2 -o radlandia radlandia.cpp
./radlandia < "caso teste/1.in"
```

Comments in the code and reports are in Portuguese unless noted otherwise.
