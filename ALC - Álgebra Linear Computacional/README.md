# ALC - Álgebra Linear Computacional

**Course:** Computational Linear Algebra  
**Semester:** 2020/2 and 2021/1  
**University:** Universidade Federal de Minas Gerais (UFMG), Department of Computer Science (DCC)

Programming exercises (EPs) applying linear algebra with NumPy in Jupyter notebooks. Each EP folder has the notebook and, when available, the PDF version and the expected outputs.

## Contents

| Folder | Description | Tech |
|---|---|---|
| [EP1](EP1) | Introductory NumPy exercises on matrices and vectors. | Python, NumPy |
| [EP2](EP2) | PageRank. | Python, NumPy |
| [EP3](EP3) | Image compression with SVD and eigenfaces. | Python, NumPy |
| [EP4](EP4) | PCA, simple and multiple linear regression. | Python, NumPy |
| [EP5](EP5) | Regression (two versions: 2020/2 and the corrected 2021/1 version). | Python, NumPy, pandas |

Most code comments and reports are written in Portuguese.
