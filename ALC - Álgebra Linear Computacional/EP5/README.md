# EP5

**Programming Exercise 5**  
Course: [ALC - Álgebra Linear Computacional](../README.md) (Computational Linear Algebra), 2020/2 and 2021/1

Two versions of the fifth exercise: linear regression on a cereal dataset (2020/2) and eigenvalues, singular values and the Gauss-Jacobi and Gauss-Seidel methods (2021/1).

## Files

- [`EP5.ipynb`](EP5.ipynb): 2020/2 version: regression.
- [`EP5_corrigido.ipynb`](EP5_corrigido.ipynb): 2021/1 version: eigenvalues, singular values, Gauss-Jacobi and Gauss-Seidel.
- [`Gabarito da Lista 5.pdf`](Gabarito%20da%20Lista%205.pdf): Answer key from the instructors.
- [`SaidasEsperadasEP5.pdf`](SaidasEsperadasEP5.pdf): Expected outputs.
- [`cereal.txt`](cereal.txt): Dataset.
- [`lista5_atualizada.pdf`](lista5_atualizada.pdf): Assignment statement (Portuguese).

## How to run

Open the notebooks in Jupyter or Google Colab. `cereal.txt` is the dataset used by `EP5.ipynb`.

Comments in the code and reports are in Portuguese unless noted otherwise.
